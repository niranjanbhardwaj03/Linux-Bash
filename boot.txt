# Password Set to Boot Mode in Ubuntu OS
#--------------------------------------------------------
Command: grub-mkpasswd-pbkdf2
then set your password: mypass123
After that you will get a SHA512 Secret Key > save it into a file... 
Example: boot-secretKey.txt
---------------------------------------------------------
Now open a File:
sudo nano /etc/grub.d/40_custom

in the file bottam add these below given line:

set superusers="root"
password_pbkdf2 root  Paste_Your_Secret-SHA512_Key
